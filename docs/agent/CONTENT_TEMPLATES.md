# Content Templates Reference

Templates used by `file_executor._generate_file_content` for each extension.
Function name / entity name is extracted from the task description when possible.

---

## .py

```python
"""
<task description, first 200 chars>
"""


def <func_name>():
    """
    <task description, first 120 chars>
    """
    pass


if __name__ == "__main__":
    <func_name>()
```

`func_name` extraction order: `\b([a-z_]+)\s+function` → `function\s+<name>` → `def\s+<name>` → `implement\s+<name>` → fallback `main`.

---

## .js / .ts — component

Triggered when task description contains "component".

```js
/**
 * <task description>
 */

function <Name>(props) {
    return (
        <div className="<name>">
            {/* <task description, 80 chars> */}
        </div>
    );
}

export default <Name>;
```

---

## .js / .ts — class

Triggered when task description contains "class".

```js
/**
 * <task description>
 */

class <Name> {
    constructor() {
        // <task description, 80 chars>
    }
}

export default <Name>;
```

---

## .js / .ts — function (default)

```js
/**
 * <task description>
 */

function <funcName>() {
    // <task description, 80 chars>
}

export { <funcName> };
```

Entity name extracted via `(?:component|class|function)\s+<Name>` or `(?:create|add|implement)\s+<UpperName>`.

## _generate_modification — intent detection

| Task pattern | Action |
|---|---|
| `add (function\|method\|def) <name>` | Append function stub at end of file |
| `update\|replace section <heading>` | Find heading in markdown, insert note below |
| *(default)* | Append language-specific comment block |

Comment styles: `.py` → `# ...`, `.js`/`.ts` → `// ...`, `.yaml` → `# ...`, other → `<!-- ... -->`.
