# SMTP readiness smoke

Дата: 2026-05-01

## Назначение

Этот smoke нужен, чтобы не выпускать платную платформу без рабочих писем.

## Проверки

- `/api/auth/register` создает аккаунт.
- Backend пытается отправить welcome email.
- Reset password endpoint создает одноразовый token.
- Пользователь получает письмо.
- Новый пароль можно задать по token.
- Старый пароль после reset не подходит.
- Повторное использование reset-token отклоняется.

## Статус

Автоматический SMTP smoke пока не включен, потому что production SMTP ключи не настроены. Это блокер перед платным запуском, но не блокер для доработки demo/MVP.
