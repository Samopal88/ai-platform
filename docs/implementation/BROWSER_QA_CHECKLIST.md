# Browser QA Checklist

Date: 2026-04-30

## Desktop

- Open `/chat`.
- Open and close sidebar.
- Create a personal chat.
- Change model through the model picker.
- Send a message.
- Open tariffs.
- Open documentation.
- Open login modal, register/login, logout.
- Check text does not overflow buttons or cards.

## Mobile Width

- Sidebar opens as drawer and closes by backdrop.
- Topbar controls fit without horizontal scroll.
- Model picker opens inside viewport.
- Composer remains usable.
- Auth and tariff modals fit on screen.

## Product States

- Guest state is understandable.
- Logged-in state shows account email.
- YooKassa disabled state says checkout is demo/soon.
- Media disabled state says provider is not configured.
- Documentation pages load from navigation.
