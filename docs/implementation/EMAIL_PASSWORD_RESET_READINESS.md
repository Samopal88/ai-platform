# Email and password reset readiness

Дата: 2026-05-01

## Текущее состояние

- Email/password регистрация и вход уже есть.
- Пользователь принимает условия при регистрации.
- Сервис email есть, но SMTP production-настройки не включены.
- Восстановление пароля не считается production-ready без реальной отправки писем.

## Что нужно для продаж

- Подключить SMTP провайдера.
- Добавить production-переменные:
  - `SMTP_HOST`
  - `SMTP_PORT`
  - `SMTP_USERNAME`
  - `SMTP_PASSWORD`
  - `SMTP_FROM_EMAIL`
  - `SMTP_FROM_NAME`
- Проверить welcome email.
- Проверить reset password email.
- Проверить срок жизни reset-token.
- Проверить, что reset-token одноразовый.
- Проверить rate-limit на отправку писем.

## UX gate

Вход должен быть обычным:

- email;
- пароль;
- кнопка `Войти`;
- ссылка `Забыли пароль?`;
- ссылка `Зарегистрироваться`;
- вход из левого нижнего угла интерфейса.

Временный вход через sync/token не должен быть основным публичным сценарием.
