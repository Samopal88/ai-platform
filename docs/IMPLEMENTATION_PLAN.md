# IMPLEMENTATION_PLAN
## AI Workspace Platform MVP

---

# Общий принцип

Разработка ведётся по этапам.

Каждый этап:
- ограничен по объёму
- даёт рабочий результат
- может быть проверен пользователем
- не ломает предыдущие этапы

GPT-5.4 управляет задачами.
Claude Code реализует задачи.
