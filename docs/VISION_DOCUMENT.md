# VISION DOCUMENT
## AI Workspace Platform (working title)

---

## 1. Идея продукта

Платформа представляет собой **AI-workspace**, где пользователь работает с нейросетями через чат, проекты и файлы.

Пользователь взаимодействует с системой аналогично ChatGPT, но дополнительно получает:

- проекты с памятью контекста
- поддержку нескольких моделей AI
- работу с файлами внутри проектов
- возможность редактирования файлов через AI
- генерацию изображений
- распознавание голосовых сообщений
- управление историей и контекстом проекта
- web-поиск

Платформа не является файлообменником.  
Файлы используются как рабочий контекст для AI.

---

## 2. Основной пользовательский сценарий

Пользователь создаёт проект и работает внутри него через чат.

AI:

- понимает контекст проекта
- помнит предыдущие задачи
- использует загруженные файлы
- редактирует файлы при необходимости
- использует выбранную модель
- может искать информацию в интернете

Пример:

пользователь создаёт проект  
"Маркетинг 2026"

загружает:

- стратегию
- таблицу бюджета
- брендбук

далее общается с AI:

- задаёт вопросы
- просит изменить документы
- просит создать таблицы
- генерирует изображения
- продолжает работу через время

AI сохраняет контекст проекта.

---

## 3. Проекты

Проект является основной единицей работы.

Проект содержит:

- чаты
- файлы
- индекс файлов
- память проекта
- summaries
- настройки моделей
- историю действий
- задачи агентов

Контекст между проектами не смешивается.

---

## 4. Чат

Основной интерфейс взаимодействия с AI.

Через чат пользователь может:

- задавать вопросы
- ставить задачи
- загружать файлы
- редактировать файлы
- генерировать изображения
- отправлять голосовые сообщения
- выбирать модель

Чаты имеют ограниченный активный контекст.

Старые сообщения автоматически сжимаются в summaries.

---

## 5. Поддержка нескольких моделей (OpenCode)

Пользователь может выбирать модель для работы.

Поддерживаются модели:

### Claude
- Opus 4.6
- Sonnet 4.6
- Haiku 4.5

### OpenAI
- GPT-5.4
- GPT-5.2
- GPT-4.1

### Google
- Gemini 3 Pro
- Gemini 2.5 Pro

Выбор модели может происходить:

- на уровне чата
- на уровне сообщения

OpenCode используется как единый слой подключения моделей.

---

## 6. Работа с файлами

Файлы являются частью проекта.

Файлы используются AI для понимания контекста.

Поддерживаемые типы:

xlsx  
csv  
docx  
pdf  
txt  
md  
json  
yaml  
png  
jpg  
webp  
py  
js  
ts  
sql  
html  
css  

---

### режимы файлов

**read-only**  
AI может читать файл

**editable**  
AI может изменять файл

**generated**  
файл создан AI

---

### редактирование файлов через AI

пример:

пользователь:

добавь лист прогноз в excel

AI:

изменяет файл

сохраняет новую версию

показывает результат

---

### версии файлов

версионирование:

выключено по умолчанию

можно включить вручную

максимум:

3 версии файла

старые версии удаляются

---

### ограничения файлов

максимальный размер одного файла:

50 MB

---

## 7. Индексация файлов

после загрузки файла:

система:

- извлекает текст
- разбивает на части
- создаёт embeddings
- сохраняет индекс
- сохраняет метаданные

AI использует индекс для поиска информации.

AI не перечитывает файл каждый раз.

---

## 8. Голосовые сообщения

пользователь может отправлять голосовые сообщения.

система:

- распознаёт речь
- преобразует в текст
- передаёт текст AI
- сохраняет транскрипт

голос используется только как ввод.

озвучивание ответа не входит в MVP.

---

## 9. Генерация изображений

AI может:

- создавать изображения
- изменять изображения
- использовать изображения в контексте проекта

---

## 10. Web Search

AI агент может использовать встроенный web-поиск.

Агент может:

- выполнять поисковые запросы
- открывать страницы
- читать документацию
- анализировать статьи
- извлекать информацию
- искать решения ошибок
- изучать API
- находить примеры кода

---

### ограничения web-доступа

агент НЕ:

- устанавливает программы
- выполняет сторонний код автоматически

агент только:

- читает страницы
- анализирует информацию

---

## 11. Память проекта

каждый проект имеет память.

память хранит:

- контекст задач
- факты проекта
- решения
- ограничения
- summaries

---

## 12. Compaction контекста

история чата не бесконечна.

система:

- создаёт summaries
- сохраняет важные факты
- очищает лишний контекст

---

- до 100 MB файлов на проект

- до 250 MB файлов на проект

- до 2 млн токенов

---

### ограничения

максимальный размер файла:

50 MB

### дополнительные покупки

- дополнительное хранилище
- дополнительные токены
