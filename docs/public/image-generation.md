# Генерация изображений

Платформа поддерживает продуктовый сценарий генерации изображений по текстовому описанию.

## Как это работает в интерфейсе

1. В чате нажмите `+`.
2. Выберите "Сгенерировать изображение".
3. Опишите, какую картинку нужно получить.
4. Отправьте сообщение.

Сейчас функция работает в демо-режиме: кнопка и backend API уже есть, но без настроенного провайдера платформа покажет понятное сообщение, что генерация временно выключена.

## Планируемое поведение после подключения провайдера

- генерация картинки из prompt;
- сохранение результата в историю чата;
- возможность сохранить результат в проект;
- учёт расхода токенов или медиакредитов;
- ограничения по тарифу.

## Поддерживаемые API

- `POST /api/media/images` — генерация изображения;
- при отсутствии ключей возвращает `503`, не ломая чат.
