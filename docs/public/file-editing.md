# AI-редактирование файлов

Это ключевая возможность платформы.

AI не должен молча менять файлы. Безопасный процесс:

1. Пользователь выбирает файл или просит изменить файл в чате.
2. AI готовит план изменения.
3. Платформа показывает preview/diff.
4. Пользователь нажимает approve или reject.
5. Только после approve создается новая версия файла.

## Версии

Для editable-файлов будет доступно версионирование. По умолчанию сохраняется до 3 последних версий.

## Режимы файлов

- read_only — AI может читать, но не менять
- editable — AI может предложить изменения
- generated — файл создан AI
