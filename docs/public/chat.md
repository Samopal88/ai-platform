# Текстовый чат

Чат — основной интерфейс общения с AI.

В чате можно:

- задавать вопросы
- выбирать модель
- прикладывать файлы
- создавать документы, таблицы и презентации
- использовать web search
- продолжать работу в контексте проекта

История сообщений сохраняется. Для длинных чатов будет использоваться summary/compaction, чтобы важный контекст не терялся.
