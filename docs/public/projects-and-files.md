# Проекты и файлы

Проект — отдельное рабочее пространство.

Проект содержит:

- чаты
- файлы
- память проекта
- summaries
- настройки модели
- историю AI-задач

## Файлы

Поддерживаемые типы:

- txt, md, json, yaml
- csv, xlsx
- docx, pdf
- png, jpg, webp
- py, js, ts, html, css, sql

Файлы используются как рабочий контекст AI. Платформа не является файлообменником.

## Индексация

Файлы будут извлекаться, разбиваться на chunks и индексироваться через embeddings, чтобы AI находил нужные фрагменты без загрузки всего файла в prompt.
