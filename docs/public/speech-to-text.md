# Речь в текст

Платформа должна уметь принимать аудио и превращать его в текст для дальнейшей работы в чате или проекте.

## Как это работает в интерфейсе

1. В чате нажмите `+`.
2. Выберите "Распознать аудио".
3. Загрузите аудиофайл.
4. После распознавания текст появится в поле сообщения.

Сейчас функция работает в демо-режиме: интерфейс и API готовы, но без настроенного провайдера платформа показывает понятное состояние "провайдер не настроен".

## Планируемое поведение после подключения провайдера

- распознавание голосовых заметок;
- вставка текста в composer перед отправкой;
- возможность использовать распознанный текст как контекст проекта;
- учёт расхода по тарифу.

## Поддерживаемые API

- `POST /api/media/speech-to-text` — распознавание аудио;
- при отсутствии ключей возвращает `503`, не ломая чат.
