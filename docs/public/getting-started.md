# Начало работы

1. Откройте чат.
2. Выберите модель в списке моделей.
3. Напишите первое сообщение или создайте проект.
4. Для проектов, файлов и синхронизации войдите по email и паролю.
5. Загрузите файлы в проект и задайте инструкции проекта.

## Гостевой режим

Гостевой режим подходит для быстрого теста чата в текущем браузере.

Для сохранения истории между устройствами, работы с проектами и файлами лучше войти по email.

## Вход и регистрация

Публичный сценарий должен быть обычным:

- `Войти` - для существующего аккаунта;
- `Зарегистрироваться` - для нового аккаунта;
- `Забыли пароль?` - после подключения SMTP.

Восстановление пароля считается production-ready только после проверки реальной отправки писем.

## Первый проект

Проект нужен, когда AI должен работать с файлами, инструкциями и долговременным контекстом.

После создания проекта можно:

- загрузить документы;
- задать инструкции проекта;
- создать чат внутри проекта;
- попросить AI прочитать файл или подготовить изменения к файлу;
- принять или отклонить изменения через preview/diff.

## Тарифные лимиты

Free plan имеет маленький лимит токенов, проектов и места. Если лимит закончился, интерфейс должен показать понятную ошибку и предложить тарифы.
