## Главная идея

Платформа объединяет Claude, ChatGPT, Gemini и другие AI-модели в одном русскоязычном интерфейсе. Главное отличие от обычных чат-ботов: пользователь работает в проектах, загружает файлы, а AI может использовать их как контекст и безопасно предлагать изменения через preview/diff и approve.
