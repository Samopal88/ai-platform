# Модели нейросетей

Платформа объединяет несколько семейств моделей в одном рабочем интерфейсе. Выбор модели сохраняется в чате и используется backend-роутером при следующем ответе.

## OpenAI

- GPT-5.4 — сильная универсальная модель для сложных задач, кода, файлов и рассуждений.
- GPT-5.2 — универсальная модель для ежедневной работы, анализа и аккуратных ответов.
- GPT-4.1 — быстрая и надёжная модель для текста, кода и изображений.
- GPT-4o — мультимодальная модель для быстрых диалогов, изображений и голосовых сценариев.

## Claude / Anthropic

- Claude Opus 4.6 — самая продвинутая модель Claude для глубокого анализа и больших документов.
- Claude Sonnet 4.6 — баланс качества и скорости для кода, текстов, файлов и проектной работы.
- Claude Haiku 4.5 — быстрая и экономичная модель для коротких задач и быстрых правок.

## Gemini / Google

- Gemini 3 Pro — мощная модель для рассуждений, мультимодальности и больших контекстов.
- Gemini 3.0 Flash — быстрая модель для повседневных задач и черновиков.
- Gemini 2.5 Pro — сильная модель для анализа, изображений и документов.

## Дополнительные модели

- DeepSeek Chat — экономичная модель для текстов, кода и быстрых рабочих ответов.
- DeepSeek Reasoner — модель с акцентом на пошаговую логику, математику и код.
- Grok 4 — модель xAI для быстрых ответов и анализа.
- Qwen3 Max — модель Qwen для кода, документов и многоязычных задач.

## Как выбирать

- Быстрые ответы: Claude Haiku, Gemini Flash, DeepSeek Chat.
- Документы и файлы: Claude Sonnet, GPT-5.2, Gemini Pro.
- Сложная аналитика: Claude Opus, GPT-5.4, DeepSeek Reasoner.
- Изображения и vision: модели с бейджем "Картинки".
- Короткие дешёвые задачи: starter-модели.

Если пользователь спрашивает, какая модель отвечает, платформа сообщает выбранную в интерфейсе модель и её производителя.
