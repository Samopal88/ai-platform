Политика конфиденциальности

Ниже кратко описано, какие данные обрабатываются и зачем.

1. Какие данные хранятся

  • чаты и сообщения;
  • файлы, загруженные в проекты;
  • memory entries (память проекта).

2. Как используются данные

Данные используются для работы продукта: отображение истории, контекста проекта и генерация ответов ИИ.

3. Сторонняя обработка

Часть запросов может передаваться внешним LLM-провайдерам для получения ответа модели.

4. Срок хранения

Данные могут храниться, пока ваш аккаунт активен или пока вы не удалите их в интерфейсе/по запросу. Для MVP сроки могут уточняться по мере развития продукта.

5. Контакт

По вопросам приватности: privacy@your-domain.example (заполнитель, обновите на рабочий контакт).
